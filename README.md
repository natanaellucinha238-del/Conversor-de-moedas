## 📌 Sobre o Projeto

O **WiseConvert Pro** é uma solução completa de conversão de moedas inspirada na interface e nos padrões de design de grandes fintechs globais como *Wise*, *Revolut* e *Stripe*. 

A aplicação realiza conversões dinâmicas cruzadas (BRL, USD, EUR, GBP, CAD, BTC), consumindo cotações comerciais diretamente da **AwesomeAPI / B3** e oferecendo simulações de transparência bancária, alternância de tema (Light/Dark mode) e design 100% responsivo.

---

## ✨ Recursos & Diferenciais de Nível Profissional

* 🟢 **Consumo de API REST em Tempo Real:** Integração assíncrona com `fetch` e tratamento de resiliência com fallback offline.
* 🔀 **Smart Currency Swap:** Inversão rápida de moedas com micro-animação fluida de rotação.
* 🌗 **Suporte Native Dark/Light Mode:** Alternância de tema com variáveis CSS dinâmicas.
* 📱 **Modal de Seleção com Busca:** Interface customizada de seleção de moedas com suporte a pesquisa por nome ou código.
* ⚡ **Quick Amount Presets:** Atalhos de valor rápido (+R$ 100, +R$ 500, R$ 1.000, R$ 5.000).
* 📋 **One-Click Share & Copy:** Exportação formatada da cotação para a área de transferência com Notificação Toast.
* 📈 **Sparkline Trend Chart:** Gráfico vetorial SVG exibindo estimativa de tendência do mercado financeiro.

## 🛠️ Tecnologias Utilizadas

* **Frontend:** HTML5 Semântico, CSS3 Moderno (Custom Properties, Flexbox, CSS Grid, Glassmorphism).
* **JavaScript:** Vanilla ES6+ (Async/Await, Intl.NumberFormat API, DOM Manipulation, Clipboard API).
* **API Externa:** AwesomeAPI (Cotações de moedas comerciais do Banco Central).
* **Deploy & CI/CD:** Vercel com suporte a reescrita de rotas.
